# Actividad 1 - Tema 2: Ejercicios de Programación Web

Repositorio para la primera actividad del Tema 2 de la materia de Programación Web. 

## Explicacion de los ejercicios

* **Un menú principal (index.html):** Para poder navegar entre todos los trabajos.
* **Ejercicio 1 (Hola Mundo):** La estructura básica de una página.
* **Ejercicio 2 (Texto):** Práctica de párrafos, negritas (*strong*) y cursivas (*em*).
* **Ejercicio 3 (Enlaces):** Links para ir a otras páginas y links para regresar a mis otros ejercicios.
* **Ejercicio 4 (Imágenes):** Cómo mostrar una imagen en la página jalándola desde la carpeta *img/*.
* **Ejercicio 6 (Secciones):** Práctica de cómo dividir la página usando `<header>`, `<section>` y `<footer>`.
